# Publication Roadmap: Hardware-Aware RL for Quantized UAV Arrays

This document outlines the step-by-step action plan to convert the theoretical framework and codebase developed in this repository into a high-impact telecommunications research paper (targeting journals such as *IEEE Transactions on Wireless Communications*, *IEEE IoT Journal*, or *IEEE JSAC*).

## Phase 1: Massive Computational Execution (Results Gathering)
The codebase architecture is finalized and mathematically verified. The next step is to execute the heavy computational runs required to generate the final convergence plots for the paper.

1. **Full Scale Training:**
   - Update `configs/train_config.yaml` to set `total_timesteps: 5000000` (or higher depending on cluster capability).
   - Execute `python train_multi_user.py` on a dedicated CPU/GPU cluster.
2. **Extract Learning Curves:**
   - Use MLflow to export the `ep_rew_mean` and `entropy_loss` curves.
   - **Paper Figure:** Plot these curves to demonstrate the agent overcoming initial exploration paralysis via the Curriculum Learning phase.
3. **Generate Benchmark Table:**
   - Run `python evaluate_final.py` using the fully trained model.
   - **Paper Table 1:** Use the outputted table to directly compare single-user baselines (S-FCFS, S-PF), generic multi-user baselines (M-FCFS), the deterministic PINN heuristic (M-PINN-Greedy), and the proposed RL-PPO agent.

## Phase 2: Core Narrative & Paper Structuring
The paper must weave the array physics (the "why") into the machine learning solution (the "how").

* **Proposed Title:** *Hardware-Aware Spatial Orchestration for Quantized UAV Antenna Arrays: A PINN-Assisted Reinforcement Learning Approach.*

### Section Outline
1. **Introduction & Motivation**
   - **Context:** 5G/6G UAV relays require Massive MIMO for capacity, but high-resolution digital baseband hardware is too heavy and power-hungry for drone payloads.
   - **The Problem:** Deploying low-cost 1-bit or 2-bit quantized arrays destroys classical null-steering capabilities (Zero-Forcing/MMSE fail due to massive quantization noise floors).
   - **The Hypothesis:** Interference under cheap hardware cannot be solved via baseband compensation; it must be solved via a higher-order, hardware-aware spatial orchestrator.
2. **System Model & The PINN Surrogate**
   - Introduce the `PairwiseInterferencePINN`.
   - Explain the physical laws embedded in the model: 1-bit mirror ambiguities ($180^\circ$ grating lobes), 2-bit harmonic lobes, and the absolute quantization noise floor.
   - **Paper Figure:** Use the plots generated by `diagnostics/verify_pinn_accuracy.py` to prove the PINN accurately acts as a lightweight digital twin of the raw array physics.
3. **The RL Architecture (The Orchestrator)**
   - Detail the single-agent PPO architecture.
   - Explain the observation space: specifically how injecting the $N \times N$ `pinn_interference_matrix` acts as a deterministic "Carrier Sense" graph for the RL agent.
   - Detail **Reward-Weighted Positioning:** Explain how the UAV dynamically shifts its trajectory toward the centroid weighted by user urgency `(delay + 1.0) * remaining_need`, implicitly solving the mobility-fairness problem without expanding the RL action space.
4. **Curriculum Learning & Penalty Shaping**
   - Detail the "Exploration Paralysis" phenomenon inherent in 4096-dimensional unmasked environments.
   - Explain how the `CurriculumCallback` dynamically scales the gambling interference penalty over time to bootstrap learning.
5. **Results & Evaluation**
   - Present the Benchmark Table.
   - Highlight that `RL-PPO` massively outperforms `M-FCFS` because it actively utilizes the PINN matrix to avoid spatial interference traps that the blind heuristic falls into.

## Phase 4: Future Extensions (Conclusion)
Conclude the paper by outlining how this highly scalable architecture paves the way for future research:
- **Empirical Fine-Tuning:** The PINN is currently bounded by simulated physics. Future work can fine-tune the PINN weights using real-world CSI data collected from a physical UAV flight, seamlessly transitioning the architecture from simulated to empirical environments.
- **Swarm Scalability:** The relative spatial penalty logic (Angular Separation and Distance Ratios) used by the PINN inherently scales to multi-UAV (swarm) scenarios without requiring absolute GPS coordinate coordination.
